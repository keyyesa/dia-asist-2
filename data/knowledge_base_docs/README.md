# Knowledge base documents

The `.txt` files in this folder are **placeholder / demo content only**, so the system has
something to learn from right after you unzip it.

**Before any real or academic use, replace or supplement them with the official documents:**

- ADA "Standards of Care in Diabetes" (current year) — https://diabetesjournals.org/care
- WHO diabetes guidelines and fact sheets — https://www.who.int/health-topics/diabetes
- Relevant PubMed research articles — https://www.ncbi.nlm.nih.gov/books/NBK25501/

Add documents (`.pdf`, `.txt`, `.md`, `.docx`) in either of two ways:

1. **In the app:** open *Knowledge Base* → upload files → they are trained automatically
   (or press **Train**).
2. **From the terminal:** copy files into this folder and run `python ingest.py`.

(This README itself is never indexed.)
